<div class="textcontainer"> <p class="margin"> </p> <h3>Week 6: Electronic Inputs</h3> <h4>Project Documentation: Rotating Capacitor Sensor</h4> <p style="font: 15px Montserrat-Light;"> This project focuses on the development of a sensor that changes its capacitance value based on the angle of overlap between two rotating capacitor plates. The design leverages the principles of variable capacitance, providing a practical application of this concept. For additional context and reference materials, please refer to the resources provided separately. </p> <h4>Components and Assembly</h4> <h5>Capacitor Plates</h5> <p style="font: 15px Montserrat-Light;"> The core of this sensor consists of two circular plates, precisely fabricated using a laser cutter. To create the conductive surface necessary for capacitance measurement, thin copper sheets were carefully adhered to cover half of each plate. This design allows for variable capacitance as the plates rotate relative to each other. </p> <div style="display: flex; justify-content: center; align-items: center; margin: 20px 0;"> <img src=".\Rotary Sensor\soldered_sensor.JPEG" alt="Capacitor plates with copper regions" style="width: 50%;"> </div> <h4>Programming and Data Acquisition</h4> <p style="font: 15px Montserrat-Light;"> The system was programmed using Arduino to measure capacitance and log data in real-time. The following code was implemented for the capacitive sensor: </p> <div style="max-height: 400px; overflow-y: auto; border: 1px solid #ccc; border-radius: 5px; background-color: #f9f9f9; padding: 15px; margin: 20px;"> <pre style="font-family: 'Courier New', monospace; font-size: 14px; line-height: 1.5;"> <code> long result; //variable for the result of the tx_rx measurement. int analog_pin = A3; int tx_pin = 4; void setup() { pinMode(tx_pin, OUTPUT); //Pin 4 provides the voltage step Serial.begin(9600); } void loop() { result = tx_rx(); Serial.println(result); } long tx_rx(){ // Function to execute rx_tx algorithm and return a value // that depends on coupling of two electrodes. // Value returned is a long integer. int read_high; int read_low; int diff; long int sum; int N_samples = 100; // Number of samples to take. Larger number slows it down, but reduces scatter. sum = 0; for (int i = 0; i < N_samples; i++){ digitalWrite(tx_pin,HIGH); // Step the voltage high on conductor 1. read_high = analogRead(analog_pin); // Measure response of conductor 2. delayMicroseconds(100); // Delay to reach steady state. digitalWrite(tx_pin,LOW); // Step the voltage to zero on conductor 1. read_low = analogRead(analog_pin); // Measure response of conductor 2. diff = read_high - read_low; // desired answer is the difference between high and low. sum += diff; // Sums up N_samples of these measurements. } return sum; } // End of tx_rx function. </code> </pre> </div> <h4>Experimental Procedure</h4> <p style="font: 15px Montserrat-Light;"> To evaluate the performance of the rotating capacitor sensor, the following procedure was followed: </p> <ol style="font: 15px Montserrat-Light;"> <li>The rotating capacitor was connected to an Arduino microcontroller for real-time data acquisition.</li> <li>Capacitance measurements were recorded while incrementally adjusting the angle of overlap between the plates.</li> <li>Serial monitor readings were captured for each angle to analyze the relationship between angle and capacitance.</li> </ol> <div style="display: flex; justify-content: center; align-items: center; margin: 20px 0;"> <img src=".\Rotary Sensor\Senor_attached_to_arduino.JPEG" alt="Experimental setup with Arduino and rotation mechanism" style="width: 50%;"> </div> <h4>Observations and Results</h4> <p style="font: 15px Montserrat-Light;"> Throughout the experiment, several key observations were made: </p> <ol style="font: 15px Montserrat-Light;"> <li>As the overlap angle between the plates increased, the capacitance also increased.</li> <li>The relationship between the angle of overlap and capacitance was found to be approximately linear, as demonstrated in the graph below.</li> </ol> <div style="display: flex;
