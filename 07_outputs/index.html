These tags contain a unique identifier that can be used for various applications, such as access control, inventory tracking, or identification purposes. The scanner communicates with the tag wirelessly, making it a convenient and efficient tool for data retrieval. </p> <p style="font: 15px Montserrat-Light;"> I created an input-output device using the MFRC522 RFID sensor, an LCD screen, and an ESP32 module. The primary goal was to test the functionality of the RFID sensor and ESP32 module, both of which I plan to use in my final project. Additionally, this setup serves as a tool to quickly read and display RFID card IDs throughout the course of my project. </p> <h5>Wiring Diagram</h5> <p style="font: 15px Montserrat-Light;"> Below is the wiring setup for connecting the MFRC522 RFID sensor, LCD screen, and ESP32 module: </p> <div style="display: flex; We tried to troubleshoot this a number of ways, including using buffer to help the program read and write the audio file at the correct sample. <div style="max-height: 400px; overflow-y: auto; border: 1px solid #ccc; border-radius: 5px; background-color: #f9f9f9; padding: 15px; margin: 20px;"> <pre style="font-family: 'Courier New', monospace; font-size: 14px; line-height: 1.5;"> <code> #include <SD.h> #include <SPI.h> File wavFile; unsigned int sampleRate = 0; void playWav(const char *filename) { wavFile = SD.open(filename); if (!wavFile) { Serial.println("Failed to open WAV file!"); return; } unsigned char header[44]; if (wavFile.read(header, 44) < 44) { Serial.println("Invalid WAV file!"); wavFile.close(); return; } sampleRate = header[24] | (header[25] << 8) | (header[26] << 16) | (header[27] << 24); Serial.print("Sample Rate: "); Serial.println(sampleRate); uint8_t buffer[512]; while (wavFile.available()) { size_t bytesRead = wavFile.read(buffer, sizeof(buffer)); for (size_t i = 0; i < bytesRead; i += 4) { // Extract left and right channels (16-bit each) int16_t left = buffer[i] | (buffer[i + 1] << 8); int16_t right = buffer[i + 2] | (buffer[i + 3] << 8); // Mix stereo to mono by averaging int16_t mixed = (left + right) / 2; // Scale 16-bit sample to 8-bit for DAC uint8_t scaledSample = (mixed >> 8) + 128; dacWrite(25, scaledSample); delayMicroseconds(1000000 / sampleRate); } } wavFile.close(); Serial.println("Playback finished."); } void setup() { Serial.begin(115200); if (!SD.begin(5)) { Serial.println("SD card initialization failed!"); return; } playWav("/Not_Like_Us.wav"); } void loop() { // Do nothing } </code> </pre> </div> </div>
