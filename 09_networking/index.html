Currently, this input is limited to a 5-second duration to ensure system stability.</li> <li>An I2S microphone captures the audio input in .raw format. Custom functions then convert this raw audio data into a .wav file format suitable for further processing.</li> <li>The .wav file is transmitted to OpenAI's Whisper API, a powerful speech-to-text model that transcribes the audio input into text.</li> <li>The resulting transcript is then sent to the Perplexity API for processing. This API was chosen for its unique combination of AI capabilities and access to real-time information, providing comprehensive and up-to-date responses. Evan was also very familiar with the Perplexity API.</li> <li>Once the AI generates a response, it is converted back into audio format using OpenAI's text-to-speech model.</li> <li>In the current implementation, the audio response is sent back to the computer via a serial port connection. Future iterations will incorporate on-device audio playback through an integrated speaker.</li> </ol> <p style="font: 15px Montserrat-Light;"> Throughout this process, the TFT screen displays the current operational state, keeping the user informed of the assistant's activities. </p> <h5>Technical Challenges and Solutions</h5> <p style="font: 15px Montserrat-Light;"> During the development process, we encountered several significant challenges: </p> <ul style="font: 15px Montserrat-Light;"> <li><strong>Microphone Implementation:</strong> Integrating and debugging the microphone proved to be a complex task.
